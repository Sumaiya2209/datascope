# DataScope Performance Report

Generated by `npm run perf:test`. Results are written only after the benchmark
completes against the dedicated PostgreSQL performance database. No estimates
or synthetic measurements are recorded here.

The workload seeds and verifies 1,000,000 records, measures authenticated
records API response times for filtering and shallow/deep offset pagination,
compares a cold count-cache request to warm-cache requests, counts API calls
while typing into the Explorer search box, and captures PostgreSQL
`EXPLAIN (ANALYZE, BUFFERS, FORMAT JSON)` output.
